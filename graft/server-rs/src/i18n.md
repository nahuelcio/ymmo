# server-rs/src/i18n.rs

The app's bilingual (Argentine Spanish / English) text layer: a Lang type plus helpers that pick localized strings, resolve localized display names for game entities, and format numbers with the right thousands separator.

- Lang · enum · L5-L5 — Identifies which of the two supported languages (Argentine Spanish or English) content should be rendered in.
- parse · function · L8-L10 — Turns a language code string into a Lang, rejecting anything that isn't "es" or "en".
- en · function · L11-L11 — Shorthand predicate the whole module uses to test whether the active language is English.
- tr · function · L15-L15 — Selects between paired Spanish and English literal strings for inline UI labels.
- trs · function · L16-L16 — Same Spanish/English selection as tr but for already-built String values.
- item_name · function · L18-L20 — Displays an item's localized name, falling back to the raw id when the item is unknown.
- teleport_name · function · L21-L23 — Displays a teleport's localized name, falling back to the raw id when the teleport is unknown.
- npc_title · function · L24-L26 — Supplies an NPC's localized title, defaulting to empty when the NPC doesn't exist.
- npc_greeting · function · L27-L29 — Supplies an NPC's localized greeting text, defaulting to empty when the NPC doesn't exist.
- npc_lines · function · L30-L32 — Returns an NPC's localized dialogue line list, or an empty slice when the NPC doesn't exist.
- zone_name · function · L33-L41 — Resolves a Spanish place name to its English display name by searching towns, the wilderness, zones, and raids in order, returning the original name when the language is Spanish or nothing matches.
- fmt_int · function · L44-L53 — Renders integers with locale-correct thousands grouping so numbers read "1.234" in Spanish and "1,234" in English.
